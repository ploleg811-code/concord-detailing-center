# Concord Detailing Center — сайт детейлинг-центра

Многостраничный сайт (8 страниц) для детейлинг-центра **Concord Detailing Center**
(Санкт-Петербург, Стартовая ул., 10). Чистый HTML/CSS/JS, без сборщика и без зависимостей —
достаточно открыть `index.html` в браузере.

---

## 📁 Структура

```
Koncord-site/
├── index.html                 Главная
├── services.html              Услуги и цены (полный прайс + FAQ)
├── service-polirovka.html     Полировка и коррекция ЛКР
├── service-keramika.html      Защитное керамическое покрытие 9H
├── service-okleyka.html       Защитная оклейка кузова
├── service-himchistka.html    Химчистка салона
├── portfolio.html             Портфолио: до / после
├── contacts.html              Контакты, карта, отзывы, FAQ
├── robots.txt
├── sitemap.xml
└── assets/
    ├── css/style.css          Дизайн-система и все стили
    ├── js/main.js             Скролл, анимации, модалка, форма
    ├── favicon.svg
    └── img/                   Фотографии студии (15 шт.)
```

## 🚀 Как открыть

Просто откройте `index.html` двойным щелчком. Для корректной работы карты и шрифтов
лучше запустить локальный сервер:

```bash
cd Koncord-site
python -m http.server 8000
# затем откройте http://localhost:8000
```

## 🎨 Дизайн-система

| Токен | Цвет | Назначение |
|---|---|---|
| `--bg` | `#111318` | Основной фон (графит) |
| `--bg-2` | `#20242B` | Вторичный фон (антрацит): карточки, меню, цены, отзывы |
| `--bg-3` | `#181C22` | Третий уровень: подвал, полосы-разделители |
| `--text` | `#F2F3F4` | Основной текст |
| `--muted` | `#98A1AC` | Второстепенный текст |
| `--accent` | `#C7CFD9` | Светло-серый акцент: кнопки, плашки, выделения |
| `--accent-text` | `#D5DCE4` | Акценты в тексте (подзаголовки, ссылки) |

Палитра монохромная: тёмный графит + светло-серые акценты. Никакого «бежевого золота» —
акцент намеренно светлее фона, чтобы не сливаться с ним.

Шрифты: **Unbounded** (заголовки) + **Inter** (текст), подключены с Google Fonts,
есть системный фолбэк — сайт корректно выглядит и без интернета.

## ✨ Что реализовано

* **Понятный первый экран** — что делает студия, где находится, три способа записи.
* **Услуги и цены** — 6 карточек услуг + полный прайс с разбивкой по категориям (вкладки).
* **Портфолио до/после** — 3 сравнительных слайдера на главной + 12 работ в портфолио.
* **Запись в 1–2 шага** — модальное окно с формой (марка авто, услуга, дата), звонок,
  Telegram, WhatsApp.
* **Отзывы, адрес и карта** — реальные отзывы с Яндекс.Карт, график работы, Яндекс-карта
  с тёмной темой, кнопка «построить маршрут».
* **SEO** — уникальные `<title>`/`<meta description>` на каждой странице, canonical,
  Open Graph, JSON-LD (`AutoWash`, `Service`, `FAQPage`), `sitemap.xml`, `robots.txt`.
* **Анимации** — тяжёлый плавный скролл (инерционное «докручивание»), reveal-эффекты
  при появлении в экране, параллакс фонов, счётчики, hover-подъём карточек, модалка
  (выезжает снизу на мобильном + появление полей каскадом), лайтбокс, бегущая строка.
* **Мобильная версия** — адаптирована под телефон: закреплённая нижняя панель
  «Записаться / Позвонить», модалка открывается как шторка снизу, поля формы крупные
  (16px, без зума iOS), тап-таргеты от 44–52px.

### Тяжёлый медленный скролл

Реализован на чистом JS в `assets/js/main.js` (раздел 1): колесо мыши перехватывается,
позиция плавно «догоняет» цель через экспоненциальное сглаживание (`EASE = 0.075`).
На тач-устройствах используется нативный скролл. При `prefers-reduced-motion` анимации
отключаются.

Чтобы сделать скролл ещё тяжелее — увеличьте `EASE` (например `0.05`).
Чтобы легче — уменьшите (например `0.12`).

## 📝 Что нужно заменить перед публикацией

1. **Форма заявки (Formspree)** — в `assets/js/main.js`, объект `CONFIG`:
   ```js
   formEndpoint: 'https://formspree.io/f/xxxxx'   // ← ваш ID с formspree.io
   ```
   Пока ID не заменён, форма формирует письмо и открывает почтовый клиент (запасной вариант).
2. **Telegram** — `CONFIG.telegram` в `assets/js/main.js` и ссылки `t.me/...` в HTML.
3. **Фотографии** — лежат в `assets/img/` (источник: Яндекс.Карты, карточка организации).
   Замените на собственные снимки работ, сохранив имена `p01.jpg … p15.jpg`,
   либо поправьте `src` в HTML. **Важно:** фотографии с Яндекс.Карт принадлежат их авторам —
   перед публикацией замените их на свои или получите разрешение.
4. **Цены и услуги** — правятся прямо в HTML-файлах (блоки `.price-row`) и в
   `assets/js/main.js` (список `SERVICES` — используется в модальной форме).
5. **Адрес, телефон, режим работы** — в шапке, подвале и на странице `contacts.html`.
6. **Домен** — в `sitemap.xml`, `robots.txt` и в `canonical` (сгенерировано как
   `https://concord-detailing.ru`, поправьте на свой).
